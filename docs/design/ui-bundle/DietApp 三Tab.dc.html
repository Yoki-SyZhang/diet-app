三个 Tab 的页面设计

按 PRD §4.2 / SPEC §2 的组件职责搭建：记录 = 对话录入 + 今日明细 + 常吃库，看板 = 双联动趋势图 + 今日详情 + 减脂计划 + 身体维度 + 运动录入，我的 = BMR + 基础信息 + 身体维度 + 握拳尺寸。三个屏都可点击，底部 Tab 栏可互相切换。

视觉方向
主色深植物绿，数据层五色分工：摄入=红，碳水=青，蛋白=草绿，脂肪=橙，纤维=紫（均可在 Tweaks 面板调整），浅底衬深色文字、大留白、22px 圆角卡片。
数字 DM Sans / 中文 Noto Sans SC。
TAB 1 记录 · 每日交互中心
对话解析卡区分数据来源：中国成分表直接写入，网络估算带「可能不准」并需确认。今日明细按餐次分组，输入条常驻。
TAB 2 看板 · 复盘中心
7 / 14 / 30 天窗口同时驱动两张柱图；灰色自柱顶向下扣减代表运动消耗。身体维度可多选折线。
TAB 3 我的 · 设置中心
「体脂率优先」开关即时切换 BMR 公式与说明文案（1303 ↔ 1324）。目标体重不在此页，收敛在看板的减脂计划。

可以继续说：「记录页的对话卡再轻一点」·「看板换成上下滚动的分段卡片」·「给我另外两版配色」
